## Description

This report accompanies **Lesson 05** of the *Beamforming From First Principles Using MATLAB* educational project.

The report introduces the concept of **initial phase**, explains its mathematical representation, and demonstrates how phase changes the starting point of a sinusoidal waveform using MATLAB simulations.

This lesson establishes the foundation for understanding phase differences, time delay, and beamforming.

---

## Learning Objectives

After completing this lesson, readers will be able to:

* Understand the meaning of initial phase.
* Explain how phase affects a sinusoidal waveform.
* Distinguish phase from amplitude and frequency.
* Generate and compare sinusoidal signals with different initial phases using MATLAB.
* Interpret the effect of phase through graphical visualization.

## Educational Philosophy

> **Understand the concept, not memorize the equation.**

This lesson emphasizes conceptual understanding by isolating the effect of the initial phase while keeping amplitude and frequency constant.
