## Description

This report accompanies **Lesson 04** of the *Beamforming From First Principles Using MATLAB* educational project.

The report introduces the concept of **period**, explains its mathematical relationship with frequency, and demonstrates how one complete cycle of a sinusoidal waveform can be identified and measured using MATLAB.

This lesson builds the foundation for understanding phase, time delay, angular frequency, and beamforming.

---

## Learning Objectives

After completing this lesson, readers will be able to:

* Understand the meaning of period.
* Explain the relationship between period and frequency.
* Calculate the period of a sinusoidal signal.
* Measure one complete cycle using MATLAB.
* Interpret period through graphical visualization.
