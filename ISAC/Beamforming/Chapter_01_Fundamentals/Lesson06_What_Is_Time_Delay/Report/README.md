## Description

This report accompanies **Lesson 06** of the *Beamforming From First Principles Using MATLAB* educational project.

The report introduces the concept of **time delay**, explains its physical interpretation, and demonstrates how delayed sinusoidal signals can be generated and visualized using MATLAB.

This lesson lays the foundation for understanding wave propagation, phase differences, and beamforming.

---

## Learning Objectives

After completing this lesson, readers will be able to:

* Understand the meaning of time delay.
* Explain how time delay affects a sinusoidal waveform.
* Distinguish time delay from initial phase.
* Generate delayed sinusoidal signals using MATLAB.
* Interpret time delay through graphical visualization.
