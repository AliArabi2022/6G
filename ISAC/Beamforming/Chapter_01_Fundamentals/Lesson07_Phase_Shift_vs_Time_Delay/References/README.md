# References

This directory contains the reference materials used in **Lesson 07 – Phase Shift vs. Time Delay**.

The references support the theoretical concepts, mathematical derivations, and MATLAB implementation presented in the accompanying technical report.

---

## Reference Topics

The materials in this directory primarily cover:

* Phase shift
* Time delay
* Wave propagation
* Sinusoidal signals
* Signal synchronization
* Beamforming fundamentals
* Array signal processing

---

## Recommended References

The following textbooks are recommended for further study:

1. Alan V. Oppenheim and Alan S. Willsky, *Signals and Systems*, 2nd Edition, Pearson.

2. Simon Haykin and Barry Van Veen, *Signals and Systems*, 2nd Edition, Wiley.

3. John G. Proakis and Dimitris G. Manolakis, *Digital Signal Processing: Principles, Algorithms, and Applications*, 4th Edition, Pearson.

4. Constantine A. Balanis, *Antenna Theory: Analysis and Design*, 4th Edition, Wiley.

5. Harry L. Van Trees, *Optimum Array Processing*, Wiley.
