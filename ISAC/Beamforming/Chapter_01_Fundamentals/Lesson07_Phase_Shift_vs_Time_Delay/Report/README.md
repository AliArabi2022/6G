## Description

This report accompanies **Lesson 07** of the *Beamforming From First Principles Using MATLAB* educational project.

The report compares **phase shift** and **time delay**, derives their mathematical relationship, and explains why these quantities represent different physical concepts despite producing similar waveform shifts.

This lesson establishes one of the fundamental mathematical relationships used throughout beamforming and array signal processing.

---

## Learning Objectives

After completing this lesson, readers will be able to:

* Distinguish between phase shift and time delay.
* Derive the relationship between these two quantities.
* Explain why phase depends on frequency.
* Generate equivalent phase-shifted and time-delayed waveforms using MATLAB.
* Interpret the engineering significance of their relationship.
