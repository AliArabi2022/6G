# Lesson 03 — What Is Frequency?

> *Frequency determines how fast a waveform oscillates over time.*

---

## Introduction

Welcome to the third lesson of the **Beamforming From First Principles Using MATLAB** educational project.

In the previous lesson, we studied how amplitude changes the magnitude of a sinusoidal waveform. In this lesson, we investigate another fundamental parameter: **frequency**.

You will learn what frequency represents, how it affects the number of oscillations within a given time interval, and how to visualize its effect using MATLAB while keeping amplitude and phase constant.

Understanding frequency is essential before studying period, phase, time delay, and beamforming.

---

## Why This Lesson Matters

Frequency is one of the most fundamental properties of signals.

It is directly related to:

* Signal oscillation rate
* Electromagnetic wave propagation
* Wireless communication systems
* Radar signals
* Audio signals
* Carrier waves
* Antenna systems
* Beamforming applications

A clear understanding of frequency is essential for studying communication and radar engineering.

---

## Learning Question

> **What is frequency, and how does it affect the behavior of a sinusoidal waveform?**

---

## Learning Objectives

After completing this lesson, you should be able to:

* Explain the meaning of frequency.
* Describe how frequency changes a sinusoidal waveform.
* Distinguish frequency from amplitude and phase.
* Generate sinusoidal signals with different frequencies using MATLAB.
* Interpret frequency using time-domain plots.
