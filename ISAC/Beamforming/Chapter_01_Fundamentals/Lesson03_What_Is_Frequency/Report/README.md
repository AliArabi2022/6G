## Description

This report accompanies **Lesson 03** of the *Beamforming From First Principles Using MATLAB* educational project.

The report introduces the concept of **frequency**, explains its mathematical definition, and demonstrates its effect on a sinusoidal waveform using MATLAB simulations.

This lesson establishes the foundation for understanding period, phase, time delay, and beamforming.

---

## Learning Objectives

After completing this lesson, readers will be able to:

* Understand the meaning of frequency.
* Explain how frequency affects a sinusoidal waveform.
* Distinguish frequency from amplitude and phase.
* Generate and compare sinusoidal signals with different frequencies using MATLAB.
* Interpret the effect of frequency through graphical visualization.
