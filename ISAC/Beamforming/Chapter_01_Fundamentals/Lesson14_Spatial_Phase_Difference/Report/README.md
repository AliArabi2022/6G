## Report Objective

This report explains the physical origin of the spatial phase difference observed by antenna elements receiving the same incoming plane wave.

The report develops the concept from basic wave propagation to the mathematical expression of spatial phase difference and prepares the reader for antenna arrays and beamforming.

## Learning Objective

After reading this report, the reader should understand that:

* Different antenna locations create different propagation distances.
* Different propagation distances produce different arrival times.
* Different arrival times produce different phases.
* Spatial phase difference is the physical foundation of beamforming.
