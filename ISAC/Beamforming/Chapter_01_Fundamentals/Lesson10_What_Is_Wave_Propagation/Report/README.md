## Description

This report accompanies **Lesson 10** of the *Beamforming From First Principles Using MATLAB* educational project.

The report introduces the concept of **wave propagation**, explains how waves transport energy and information through space, and develops the travelling-wave equation used throughout electromagnetics, antenna theory, and beamforming.

---

## Learning Objectives

After completing this lesson, readers will be able to:

* Understand the concept of wave propagation.
* Distinguish between oscillation and propagation.
* Explain the travelling-wave equation.
* Describe the physical meaning of wave number.
* Understand why wave propagation is fundamental to antenna arrays and beamforming.
