# References

This directory contains the reference materials used in **Lesson 10 – What Is Wave Propagation?**

The references support the theoretical concepts, mathematical derivations, and MATLAB implementation presented in the accompanying technical report.

---

## Reference Topics

The materials in this directory primarily cover:

* Wave propagation
* Travelling waves
* Wave number
* Electromagnetic waves
* Energy transmission
* Information transmission
* Antenna fundamentals

---

## Recommended References

The following textbooks are recommended for further study:

1. Constantine A. Balanis, *Antenna Theory: Analysis and Design*, 4th Edition, Wiley.

2. David K. Cheng, *Field and Wave Electromagnetics*, 2nd Edition, Addison-Wesley.

3. Matthew N. O. Sadiku, *Elements of Electromagnetics*, 7th Edition, Oxford University Press.

4. Alan V. Oppenheim and Alan S. Willsky, *Signals and Systems*, 2nd Edition, Pearson.

5. John G. Proakis and Masoud Salehi, *Fundamentals of Communication Systems*, Pearson.
