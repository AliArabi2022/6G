## Description

This report accompanies **Lesson 01** of the *Beamforming From First Principles Using MATLAB* educational project.

The report introduces the concept of a sinusoidal wave, explains its mathematical representation, and demonstrates how to generate and visualize the waveform using MATLAB.

The lesson serves as the conceptual foundation for subsequent topics, including amplitude, frequency, phase, time delay, antenna arrays, and beamforming.

---

## Learning Objectives

After completing this lesson, readers will be able to:

* Understand the concept of a sinusoidal wave.
* Explain why sinusoidal signals are fundamental in engineering.
* Describe the mathematical representation of a sinusoidal signal.
* Generate and visualize a sinusoidal waveform using MATLAB.
* Interpret a simple time-domain waveform.
